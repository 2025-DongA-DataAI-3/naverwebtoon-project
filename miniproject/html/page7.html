1. Flask 서버 리소스 오류
현상
Flask 서버를 통해 HTML 렌더링 시, 로컬 실행과 달리 이미지가 화면에 출력되지 않는 현상 발생.
원인
Flask 프레임워크의 정적 파일 관리 규약(static 폴더 참조)을 무시하고 일반 상대 경로를 사용함에 따른 참조 오류.
해결
모든 이미지 자원을 static 디렉토리로 구조화하고, url_for 함수를 도입하여 서버 환경에 최적화된 동적 경로로 재설정함.


2. Flask 버튼 클릭 경로 오류
현상
ngrok URL 접속 시 메인 페이지는 보이지만, 메인 페이지에서 특정 버튼 클릭 시 다음 페이지로 이동하지 않음.
원인
버튼의 onclick이 로컬 호스트 주소(127.0.0.1:5000)를 참조하고 있어, 다른 컴퓨터에서는 해당 주소로 접근 불가.
해결
onclick을 Flask 라우트 기준(/page1 등)으로 수정하여 ngrok URL에서도 정상 동작하도록 변경.

황지용
데이터 수집&전처리 · 통계&인사이트 분석 · 시각화&보고서 제작

1. 시각화 직관성
현상
단순 표(Table) 위주의 데이터 나열로 인해 방대한 웹툰 트렌드를 한눈에 파악하기 어려움.
원인
분석 대상(15개 장르 및 요일별 랭킹)의 복잡도에 비해 시각적 전달 도구가 단조로워 인사이트 도출이 지연됨.
해결
해결: 데이터 성격에 맞춰 도넛 차트(비중), 히트맵(평점), 서브플롯(상세 분석) 등 다각적 시각화 도구를 도입하여 직관성을 극대화함.


2. 폰트 및 이모지 호환성
현상
그래프 저장 및 출력 과정에서 특정 이모지(🏆)가 렌더링되지 않고 런타임 경고(Glyph 127942)가 발생함.
원인
사용 중인 기본 폰트(Malgun Gothic)가 고해상도 이모지 및 특수 유니코드 렌더링을 지원하지 않음.
해결
불안정한 이모지 요소를 제거하고, 텍스트 태그와 명확한 강조색(Point Color)을 활용하여 출력 안정성을 확보함.


3. 라이브러리 경고 대응
현상
범주형 데이터의 그룹화 연산 시 최신 Pandas 버전에서의 호환성 경고(FutureWarning) 발생.
원인
groupby 함수의 observed 파라미터 기본값 정책 변경에 따른 잠재적 오류 가능성 감지.
해결
observed=False 옵션을 명시적으로 선언하여 데이터 연산의 정확성을 보장하고 버전 업데이트에 대비함.


4. 리소스 캐싱 문제
현상
분석 코드 수정 및 이미지 갱신 후에도 웹 페이지 상에 이전 결과물이 지속적으로 노출되는 현상.
원인
동일한 파일명 사용으로 인해 브라우저가 서버의 최신본을 확인하지 않고 로컬 캐시 데이터를 우선 로딩함.
해결
파일 관리 체계를 정비하고, 브라우저 강제 새로고침(Ctrl+F5)을 통해 캐시 데이터를 강제 갱신함으로써 데이터 불일치를 해결함.

김태준
웹크롤링 · 데이터 후처리 · 페이지 디자인 및 제작

1. 데이터 수집의 한계
현상
기본 API가 제공하는 정량적 정보만으로는 웹툰의 세부적인 특징을 심층 분석하기에 정보량이 부족함.
원인
플랫폼 제공 API의 규격화된 데이터 포맷만으로는 실제 서비스상의 정성적인 정보들을 포착할 수 없음.
해결
Selenium 기반의 크롤링 기법을 병행하여 세부 속성을 추가 확보하고, 데이터 매핑(Mapping)을 통해 분석용 데이터셋의 밀도를 높임.


2. 데이터 해석의 깊이
현상
통계 수치 기반의 결과 도출만으로는 유저의 행동 동기나 심리적 선택 이유를 설명하는 데 한계가 있음.
원인
정량적 데이터는 결과(What)를 보여주지만, 유저의 내면적 심리 기제인 원인(Why)에 대한 해석은 결여되어 있음.
해결
분석 결과에 심리학 이론(인지 부하, 면죄부 효과 등)을 분석 프레임으로 접목하여, 수치를 넘어선 전략적 인사이트와 설득력 있는 결론을 도출함.
