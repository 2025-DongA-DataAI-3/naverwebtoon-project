5-1. 트러블 슈팅
Flask 서버 이미지 출력오류 해결기 (임주은)

현상
Flask 서버에서 html 파일을 렌더링할 때 이미지가 화면에 표시되지 않았다.
HTML 파일을 단독 실행했을 때와 다른 동작을 보여 화면 구현에 어려움을 겪었다.

원인
Flask는 이미지와 같은 정적 파일을 static 폴더에서만 제공한다.
HTML에 작성한 상대경로를 그대로 사용해 서버가 이미지를 찾지 못했다.

해결
이미지 파일을 static 폴더로 이동했다.
url_for('static', filename='파일명')을 사용해 이미지 경로를 수정했다.

분석 결과를 더 잘 보여주기 위한 시행착오 (황지용)

1. 시각화 가독성 높이기
현상
단순 표(Table) 형식의 데이터 나열로 트렌드 파악이 어려움.
원인
데이터 양(15개 장르/요일별 작품)에 비해 시각적 도구가 단조로움.
해결
도넛차트(비중), 히트맵(평균 별점), 서브플롯(요일별 상세 분석) 등 데이터 성격에 맞는 다양한 차트를 활용해 직관성 극대화.


2. 폰트 호환 및 이모지 깨짐 오류
현상
그래프 저장 시 트로피 이모지(🏆)가 깨지며 Glyph 127942 경고 발생.
원인
기본 폰트(Malgun Gothic)가 특정 특수문자 및 이모지 렌더링을 지원하지 않음.
해결
이모지를 삭제하고 [1위] 텍스트와 **강조색(Red)**을 사용하여 안정적인 출력 환경 구축.


3. Pandas 라이브러리 경고 (FutureWarning)
현상
범주형 데이터 그룹화 시 최신 버전 호환성 경고 발생.
원인
groupby 함수 내 observed 파라미터의 기본값 정책 변경.
해결
**observed=False**를 명시적으로 선언하여 코드의 안정성 및 버전 호환성 확보.


4. 웹 페이지 리소스 렌더링 지연
현상
분석 코드 재실행 후에도 HTML 페이지에 이전 그래프가 노출됨.
원인
파일명 중복(insight5.png) 및 브라우저 이미지 캐싱(Caching).
해결
이미지 저장 파일명을 통합하고, 브라우저 **강력 새로고침(Ctrl+F5)**을 통해 캐시를 강제 갱신하여 해결.
