3. 데이터 전처리 및 분석 방법론
데이터 수집

분석은 2022 웹툰 데이터와 2026 네이버 최신 웹툰 데이터 를 기반으로 수행하였다.

  • ✔ 네이버 API 기반 수집
  • ✔ Selenium 크롤링으로 데이터 보완
  • ✔ 연도별 데이터 맵핑 및 통합
데이터 전처리 및 분석 설계

연도별 웹툰 데이터를 비교 분석하기 위해 데이터 구조 통합 및 정제 과정을 수행.

  • ✔ 핵심 컬럼 선별 (title, genre, age, ratings)
  • ✔ 평점 기준 내림차순 정렬 후 상위 추출
  • ✔ 2026 웹툰 크롤링 데이터와 Merge 수행
  • ✔ 결측 평점 보완 및 title 오타 데이터 정정
  • ✔ 인덱스 재정렬 및 분석용 데이터셋 구축
최종 분석 데이터 구조

전처리를 통해 구축된 데이터셋은 웹툰 소비 패턴 분석이 가능하도록 구조화.

  • ✔ 장르 트렌드 변화 분석
  • ✔ 요일별 인기 작품 분포 비교
  • ✔ 평점 기반 콘텐츠 품질 분석
  • ✔ 상위 랭킹 작품 패턴 도출
